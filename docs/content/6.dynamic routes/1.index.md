# 🔀 Dynamic Route System

The boilerplate includes a sophisticated dynamic route system that automatically generates routes based on ODOO content, supporting both build-time and runtime route resolution.

## How It Works

The system operates through two main components:

1. **Routes Generator Module** - Fetches and generates routes at build time
2. **Route Resolver API** - Resolves routes at runtime using Redis cache

### Build-Time Route Generation

The routes generator module automatically creates routes for all categories, products, and website pages:

```typescript
// modules/routes-generator/index.ts
export default defineNuxtModule({
  async setup(_, nuxt) {
    const odooBaseUrl = `${process.env.NUXT_PUBLIC_ODOO_BASE_URL}/graphql/vsf`
    const swrValue = Number(process.env.NUXT_SWR_CACHE_TIME || 300)

    // Fetch all slugs from ODOO
    const [categorySlugs, productSlugs, websitePagesUrls] = await Promise.all([
      fetchCategorySlugs(),    // e.g., ['/men', '/women/shoes', '/electronics']
      fetchProductSlugs(),     // e.g., ['/product/sneakers', '/product/laptop']
      fetchWebpageSlugs(),     // e.g., ['/about-us', '/privacy-policy']
    ])

    // Add SWR cache rules for each route
    categorySlugs.forEach((slug) => {
      extendRouteRules(slug, { swr: swrValue })
    })

    productSlugs.forEach((slug) => {
      extendRouteRules(slug, { swr: swrValue })
    })

    // Generate dynamic pages
    nuxt.hook('pages:extend', (pages: NuxtPage[]) => {
      // Category pages
      categorySlugs.forEach((slug) => {
        pages.push({
          name: slug.replace(/^\//, '').replace(/\//g, '-'),
          path: slug,
          file: '~/layers/category/custom-pages/category-page.vue',
        })
      })

      // Product pages
      productSlugs.forEach((slug) => {
        pages.push({
          name: slug.replace(/^\//, '').replace(/\//g, '-'),
          path: slug,
          file: '~/layers/product/custom-pages/product-page.vue',
        })
      })
    })
  },
})
```

### Runtime Route Resolution

For routes not available at build time, the system uses a route resolver API:

```typescript
// server/api/route-resolver/index.ts
export default defineEventHandler(async (event) => {
  const query = getQuery(event)
  const slug = query.slug as string
  
  if (!slug) {
    throw createError({
      statusCode: 400,
      message: 'Slug parameter is required',
    })
  }

  // Check Redis cache for route type
  const redisKey = `slug:${encodeURIComponent(slug)}`
  const data = await useStorage('slug').getItem(redisKey)

  if (data) {
    const modelToRouteType: Record<string, string> = {
      'product.template': 'product',
      'product.public.category': 'category',
      'alokai.website.page': 'websitePage',
    }

    return {
      data: modelToRouteType[data],
    }
  }

  return {
    data: null,
  }
})
```

### Redis Slug Cache

The system uses Redis to store slug-to-model mappings:

```typescript
// nuxt.config.ts
nitro: {
  storage: {
    slug: {
      driver: process.env.NUXT_STORAGE_DRIVER,
      url: process.env.NUXT_STORAGE_URL,
      ttl: process.env?.NUXT_SWR_CACHE_TIME || 3600,
      retry: {
        retries: 3,
        delay: 1000,
      },
      connectTimeout: 10000,
      lazyConnect: true,
    },
  },
}
```

### Benefits

- 🚀 **Build-time Optimization** - Routes pre-generated for known content
- 🔄 **Runtime Flexibility** - New routes resolved dynamically
- 📱 **SEO Friendly** - Clean URLs with proper slugs
- ⚡ **Performance** - SWR caching for all dynamic routes
- 🎯 **Type Safety** - Proper route typing and validation
- 📊 **Analytics Ready** - Named routes for tracking

### Configuration

```bash
# .env
NUXT_PUBLIC_ODOO_BASE_URL="https://your-odoo-instance.com/"
NUXT_SWR_CACHE_TIME=3600  # Cache time for routes
NUXT_STORAGE_DRIVER=redis # For slug resolution cache
NUXT_STORAGE_URL=redis://localhost:6379
```
