# 🖼️ Image Plugin

The `getImage` plugin provides a helper function to generate optimized image URLs with automatic resizing and CDN-friendly cache filenames.

### 🎯 How It Works

The plugin transforms ODOO image URLs into optimized versions with specific dimensions and proper cache-friendly filenames.

#### Plugin Configuration

```typescript
// plugins/1.getImage.ts
import { defineNuxtPlugin } from '#app'

export default defineNuxtPlugin(async (nuxtApp) => {
  const odooUrl = nuxtApp.$config.public.odooBaseImageUrl
  
  return {
    provide: {
      getImage: (
        imagePath: string,
        width: number,
        height: number,
        name: string,
      ) => {
        const resolution = `${width}x${height}`
        return `${odooUrl}${imagePath?.replace('/', '')}/${resolution}/${name}_${resolution}`
      },
    },
  }
})
```

### 📐 Image URL Structure

The plugin follows ODOO's image URL convention:

**Base URL from API:**
```
"/web/image/website.promo/1/banner_image"
```

**Add dimensions:**
```
"/web/image/website.promo/1/banner_image/400x400"
```

**Add filename for CDN cache:**
```
"/web/image/website.promo/1/banner_image/400x400/banner_filename_400x400"
```

**Final optimized URL:**
```
"https://your-odoo-instance.com/web/image/website.promo/1/banner_image/400x400/banner_filename_400x400"
```

### 🔧 Usage Examples

#### In Vue Templates

```vue
<!-- Category page with product images -->
<template>
  <LazyUiProductCard
    v-for="productTemplate in productTemplateList"
    :key="productTemplate.id"
    :name="productTemplate?.name || ''"
    :slug="mountUrlSlugForProductVariant(productTemplate.firstVariant as Product)"

      $getImage(
        String(productTemplate.image),

        370,
        String(productTemplate.imageFilename),
      )
    "
    :image-alt="productTemplate?.name || ''"
    loading="eager"
  />
</template>
```

#### In Composables

```typescript
// composables/useProductImages.ts
export const useProductImages = () => {
  const { $getImage } = useNuxtApp()

  const getProductImage = (product: Product, width: number, height: number) => {
    return $getImage(
      String(product.image),
      width,
      height,
      String(product.imageFilename)
    )
  }

  const getProductThumbnail = (product: Product) => {
    return getProductImage(product, 150, 150)
  }

  const getProductGalleryImage = (product: Product) => {
    return getProductImage(product, 800, 800)
  }

  return {
    getProductImage,
    getProductThumbnail,
    getProductGalleryImage,
  }
}
```

### 📋 Important Rules

#### ✅ Always Use API Filenames
```typescript
// ✅ Correct - use filename from API
const imageUrl = $getImage(
  product.image,           // "/web/image/product.template/123/image_1920"
  400,                     // width
  400,                     // height
  product.imageFilename    // "product_image_123.jpg" (from API)
)

// ❌ Wrong - never use custom filenames
const imageUrl = $getImage(
  product.image,
  400,
  400,
  "my-custom-filename.jpg"  // Don't do this!
)
```

#### ✅ Always Define Width and Height
```vue
<!-- ✅ Correct - explicit dimensions for performance -->
<img 
  :src="$getImage(product.image, 370, 370, product.imageFilename)"
  :alt="product.name"
  width="370"
  height="370"
  loading="lazy"
/>

<!-- ❌ Wrong - missing dimensions -->
<img 
  :src="$getImage(product.image, 370, 370, product.imageFilename)"
  :alt="product.name"
/>
```

#### ✅ Use Appropriate Loading Strategy
```vue
<!-- ✅ Above the fold - eager loading -->
<img 
  :src="$getImage(hero.image, 1200, 600, hero.imageFilename)"
  loading="eager"
/>

<!-- ✅ Below the fold - lazy loading -->
<img 
  :src="$getImage(product.image, 370, 370, product.imageFilename)"
  loading="lazy"
/>
```

### 🚀 Performance Benefits

#### Automatic Image Optimization
- **Server-side Resizing**: ODOO automatically resizes images to requested dimensions
- **Smaller File Sizes**: Only download the exact size needed
- **CDN Caching**: Proper filenames enable efficient CDN caching
- **Bandwidth Savings**: Significant reduction in data transfer

#### Browser Performance
- **Explicit Dimensions**: Prevents layout shift (CLS)
- **Lazy Loading**: Improves page load speed
- **Proper Caching**: Browser caches images efficiently

### 🎯 Best Practices

1. **Always use API filenames** - Never create custom filenames
2. **Define explicit dimensions** - Both in function call and HTML attributes
3. **Use appropriate loading strategy** - Eager for above-fold, lazy for below-fold
4. **Choose optimal sizes** - Balance quality vs. performance
5. **Implement responsive images** - Different sizes for different devices
6. **Add proper alt text** - For accessibility and SEO

This plugin ensures that all images in your application are optimized for performance while maintaining high quality and proper caching behavior.
