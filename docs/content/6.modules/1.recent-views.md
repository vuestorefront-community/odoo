## 👁️ Recent Views Module

The Recent Views module is an external package that tracks and displays recently viewed products by storing product IDs in browser cookies and fetching product data on demand.

### 📦 Installation

The module is installed as an external dependency:

```bash
yarn add @erpgap/recent-view-products
```

```json
// package.json
{
  "dependencies": {
    "@erpgap/recent-view-products": "^1.0.0"
  }
}
```

### 🎯 How It Works

The module uses browser cookies to store product IDs and provides utilities to manage and display recently viewed products.

#### Core Composable

```typescript
// node_modules/@erpgap/recent-view-products/composables/useRecentViewProducts.ts
export const useRecentViewProducts = () => {
  const list = useCookie<Number[]>("recent-view-products");

  const addProductToRecentViews = (id: number) => {
    if (list.value?.includes(id)) {
      return;
    }
    list.value?.push(id) || (list.value = [id]);
  };

  const removeProductFromRecentViews = (id: number) => {
    list.value = list.value.filter((productId) => productId !== id);
  };

  return {
    addProductToRecentViews,
    removeProductFromRecentViews,
    list: computed(() => list.value),
  };
};
```

### 🔧 Integration Implementation

#### Product Template List Composable

```typescript
// layers/product/composables/useProductTemplateListForRecentViews.ts
import type {
  Product,
  ProductTemplateListResponse,
  QueryProductsArgs,
} from '~/graphql'
import { QueryName } from '~/server/queries/index'

export const useProductTemplateListForRecentViews = () => {
  const { list } = useRecentViewProducts()
  const { $sdk } = useNuxtApp()

  const loading = useState(
    `loading-product-template-list-recent-views`,
    () => false,
  )
  const productTemplateList = ref<Product[]>([])

  const loadProductTemplateList = async () => {
    if (list.value === undefined || list.value?.length === 0) {
      return
    }
    
    const params: QueryProductsArgs = {
      filter: {
        ids: list.value,
      } as any,
    }

    const { data } = await useAsyncData(
      () =>
        $sdk().odoo.query<QueryProductsArgs, ProductTemplateListResponse>(
          { queryName: QueryName.GetProductTemplateListQueryForRecentViews },
          params,
          { headers: useRequestHeaders() },
        ),
    )

    loading.value = false
    productTemplateList.value = data?.value?.products?.products || []
  }

  return {
    loadProductTemplateList,
    list,
    loading,
    productTemplateList,
  }
}
```

### 📊 Data Flow

#### 1. Product Viewing
```typescript
// When user visits a product page
const productId = 123

// Add to recent views
const { addProductToRecentViews } = useRecentViewProducts()
addProductToRecentViews(productId)

// Cookie updated: recent-view-products = [123]
```

#### 2. Cookie Management
```typescript
// Cookie structure
const recentViewCookie = useCookie<Number[]>("recent-view-products")

// Example cookie value
recentViewCookie.value = [123, 456, 789, 101, 202]
```

#### 3. Product Data Fetching
```typescript
// Fetch products by IDs from cookie
const { list } = useRecentViewProducts()

// Query with IDs filter
const params = {
  filter: {
    ids: list.value // [123, 456, 789, 101, 202]
  }
}

// Execute GraphQL query
const products = await $sdk().odoo.query({
  queryName: QueryName.GetProductTemplateListQueryForRecentViews
}, params)
```

### 🔧 API Integration

#### Adding to Recent Views

```typescript
// In product page
const { addProductToRecentViews } = useRecentViewProducts()

if (productVariant.value?.id) {
  addProductToRecentViews(productVariant.value.id)
}

```

#### Removing from Recent Views

```typescript
// Manual removal (if needed)
const { removeProductFromRecentViews } = useRecentViewProducts()

const handleRemoveFromRecent = (productId: number) => {
  removeProductFromRecentViews(productId)
}
```

### 🎯 Features

#### Duplicate Prevention
- Automatically prevents duplicate entries
- Maintains chronological order

#### Persistent Storage
- Uses browser cookies for persistence
- Survives browser sessions

#### Performance Optimization
- Only fetches data when products exist in cookie
- Lazy loading with `LazyProductRecentViewSlider`

#### Conditional Rendering
- Only shows section when products are available
- Graceful handling of empty states

### 🎯 Benefits

1. **User Experience**: Helps users find previously viewed products
2. **Personalization**: Creates a personalized shopping experience
3. **Performance**: Efficient cookie-based storage
4. **Flexibility**: Reusable across different pages
5. **Privacy**: Local storage, no server-side tracking
6. **Responsive**: Works on all device sizes

This module provides a seamless way to enhance the shopping experience by allowing users to easily revisit products they've previously viewed, improving conversion rates and user engagement.
