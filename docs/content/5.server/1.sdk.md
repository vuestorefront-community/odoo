# 🔌 SDK Plugin

The Alokai SDK simplifies the development process by providing pre-built functionality to enables seamless interaction between your storefront and various Commerce Platforms and third-party services.

Learn more about the Alokai SDK: https://docs.alokai.com/sdk/

### 🎯 What is the SDK?

The SDK is built using the **Vue Storefront SDK** and provides:

- **Typed Interface**: All operations are type-safe
- **Organized Modules**: Clear separation between queries, mutations, and configurations
- **Error Handling**: Centralized error management
- **Centralized Configuration**: Single point for API configuration

### 🏗️ Architecture Overview

Our implementation uses a **Nuxt-based approach** instead of the traditional Express server:

**Traditional Alokai SDK:**
- HTTP Client + Express Server (separate port)
- Generic approach for multiple frameworks
- Potential deployment issues with separate servers

**Our ERPGAP Alokai SDK:**
- `$fetch` client (from Nuxt) + Nitro/H3 server (from Nuxt)
- Unified Nuxt ecosystem
- Better performance and deployment stability

## 📡 Server API Layer

The server layer acts as a bridge between the frontend and the ODOO GraphQL API, providing three main endpoints with different caching strategies.

#### 🔍 Main Endpoints

##### 1. **POST `/api/odoo/query`** - Queries with Cache
Optimized endpoint with SWR cache for data that doesn't change frequently.

```typescript
// server/api/odoo/query.post.ts
const customCache = cachedFunction(
  async (event: any) => {
    const config = useRuntimeConfig(event)
    const body = await readBody(event)

    const response: any = await $fetch.raw(`${config.public.odooBaseUrl}graphql/vsf`, {
      method: 'POST',
      headers: {
        'accept': 'application/json',
        'content-type': 'application/json',
        'REAL-IP': getRequestIP(event) || '',
        'resquest-host': config.public.middlewareUrl || getRequestHost(event),
        'Cookie': `session_id=${getCookie(event, 'session_id')}`,
      },
      body: JSON.stringify({ query: Queries[body?.[0]?.queryName], variables: body?.[1] }),
    })

    return response
  },
  {
    maxAge: Number(process.env?.NUXT_SWR_CACHE_TIME || 3600),
    staleMaxAge: Number(process.env?.NUXT_SWR_CACHE_TIME || 3600),
    getKey: async (event) => {
      const body = await readBody(event)
      const session = await useSession(event, {
        password: 'b013b03ac2231e0b448e9a22ba488dcf',
      })
      const keyName = `cache:partner:${session?.id}`

      const currentPartnerPricelist = (await useStorage().getItem<Partner>(keyName)) || ({} as Partner)
      const isoCode = getCookie(event, 'country-iso-code') || 'us'
      const pricelist = currentPartnerPricelist?.id ? `-pricelist${currentPartnerPricelist?.id}` : ''
      const hashedParams = hasher(body?.[1] || {})

      return `${body?.[0].queryName}-${hashedParams}-${isoCode}-${pricelist}`
    },
    shouldBypassCache: async (event) => {
      const config = useRuntimeConfig(event)
      const body = await readBody(event)

      const checkIfQueryNameIsEqual = (queryName: string) => queryName === body?.[0].queryName

      if (config?.shouldByPassCacheQueryNames?.some(checkIfQueryNameIsEqual)) {
        return true
      }

      return false
    },
  },
)
```

**When to use:**
- 📦 Product data
- 🏷️ Categories
- 📄 Static content

##### 2. **POST `/api/odoo/query-no-cache`** - Queries without Cache
Endpoint for data that needs to be always up-to-date.

**When to use:**
- 👤 User data
- 🛒 Shopping cart
- 📊 Real-time inventory

##### 3. **POST `/api/odoo/mutation`** - GraphQL Mutations
Endpoint for data modification operations.

**When to use:**
- 🛒 Add/remove cart items
- 👤 Login/logout
- 📍 Manage addresses

### 🔧 SDK Configuration

```typescript
// plugins/2.sdk.ts
import { initSDK, buildModule } from '@vue-storefront/sdk'
import type { OdooModuleType } from '@erpgap/odoo-sdk'
import { OdooModule } from '@erpgap/odoo-sdk'

const SHOULD_BYPASS_ERROR_QUERIES = [
  'LoadUserQuery',
  'LoadCartQuery',
]

const avoidErrorThrowForSomeRequests = (options: any) => {
  if (options.body) {
    try {
      const queryName = JSON.parse(options.body)?.[0]?.queryName

      if (SHOULD_BYPASS_ERROR_QUERIES?.includes(queryName)) {
        return true
      }

      return false
    }
    catch (error) {
      return false
    }
  }
}

export default defineNuxtPlugin(async () => {
  const config = useRuntimeConfig()

  const sdkConfig = {
    odoo: buildModule<OdooModuleType>(OdooModule, {
      apiUrl: `${config.public.middlewareUrl}api/odoo/`,
      ofetch: $fetch.create({
        credentials: 'include',
        onResponseError({ request, response, options }) {
          if (avoidErrorThrowForSomeRequests(options) && response.status === 500) {
            return
          }
          if (
            response.status === 500
            && response._data
            && response._data?.data?.length > 0
          ) {
            const toast = useToast()
            toast.error(response?._data?.message)
          }
        },
      }),
    }),
  }

  return {
    provide: {
      sdk: () => initSDK<typeof sdkConfig>(sdkConfig),
    },
  }
})
```

### 💡 Why Three Methods Instead of Specific Functions?

**Traditional Alokai Approach:**
```typescript
// Multiple specific methods
await sdk.commerce.getProducts()
await sdk.commerce.getCategories()
await sdk.commerce.getCart()
```

**Our GraphQL-Optimized Approach:**
```typescript
// Three flexible methods for any GraphQL operation
await $sdk().odoo.query()        // Cached queries
await $sdk().odoo.queryNoCache() // Non-cached queries  
await $sdk().odoo.mutation()     // Mutations
```

**Benefits:**
- 🎯 **GraphQL Native**: Designed specifically for GraphQL backends
- 🔄 **Flexibility**: Any query/mutation can be executed
- 📦 **Smaller Bundle**: No need for dozens of specific methods
- 🚀 **Performance**: Optimized caching strategies

### 💡 Practical Example: Cache Control

```typescript
// Example usage with cache control
const loadUser = async (withoutCache: boolean = false) => {
  loading.value = true

  // Choose endpoint based on cache needs
  const query = withoutCache ? $sdk().odoo.queryNoCache : $sdk().odoo.query

  const data = await query<null, LoadUserQueryResponse>({
    queryName: QueryName.LoadUserQuery,
  })

  userCookie.value = data?.partner?.id
  user.value = data?.partner
  loading.value = false
}

// Usage:
await loadUser(false)  // With cache - data may come from cache
await loadUser(true)   // Without cache - always fetch fresh data
```

### 🔄 How to Use the SDK

#### In Composables

```typescript
// composables/useAuth.ts
export const useAuth = () => {
  const { $sdk } = useNuxtApp()

  const login = async (params: MutationLoginArgs) => {
    // Typed mutation
    const data = await $sdk().odoo.mutation<MutationLoginArgs, SignInUserResponse>(
      { mutationName: MutationName.LoginMutation }, 
      params
    )
    
    return data
  }

  const loadUser = async () => {
    // Typed query
    const data = await $sdk().odoo.query<null, LoadUserQueryResponse>({
      queryName: QueryName.LoadUserQuery,
    })
    
    return data
  }
}
```

#### In Vue Pages

```vue
<script setup lang="ts">
const { $sdk } = useNuxtApp()

const getProducts = async () => {
  const data = await $sdk().odoo.query<QueryProductsArgs, ProductsResponse>(
    { queryName: QueryName.GetProductsQuery },
    { pageSize: 20, currentPage: 1 }
  )
  
  return data.products
}
</script>
```
