# 🚀 Redis Cache System

The boilerplate uses Redis for multiple caching strategies to optimize performance. Here's how each cache layer works:

## 📍 Route Cache

The route cache system automatically caches entire page responses using Redis, with intelligent cache keys based on device type and user context.

#### How It Works

```typescript
// server/plugins/route-cache.ts
export default defineNitroPlugin((nitroApp) => {
  const handlerList: Handler[] = eval('handlers')
  const skipRoutesSet = new Set(routesToSkipCache)

  const enHandler = handlerList.filter((r) => {
    const isRouteToSkip = skipRoutesSet.has(r.route)
    return !isRouteToSkip
  })

  if (enHandler.length > 0) {
    enHandler.forEach((handler) => {
      const customHandler = cachedEventHandler(
        lazyEventHandler(handler.handler),
        {
          varies: ['user-agent', 'cookie'],
          group: 'pages',
          name: handler.route,
          getKey: (event: H3Event) => {
            const headers = getRequestHeaders(event)
            const userAgent: any = headers['user-agent']
            const flags = generateFlags(headers, userAgent)

            if (flags.isDesktop) {
              return `desktop-${event.path}`
            }
            return `mobile-${event.path}`
          },
          maxAge: Number(process.env?.NUXT_SWR_CACHE_TIME),
          swr: true,
          staleMaxAge: Number(process.env?.NUXT_SWR_CACHE_TIME),
          shouldBypassCache: (event: H3Event) => {
            return event.path === '/cart' || event.path.startsWith('/my-account/')
          },
        },
      )
      nitroApp.router.use(handler.route, customHandler)
    })
  }
})
```

#### Cache Strategy

**Device-Based Cache Keys:**
- `desktop-/product/my-product` - Desktop version
- `mobile-/product/my-product` - Mobile version

**Routes That Skip Cache:**
```typescript
const routesToSkipCache = [
  '/api/odoo/all',
  '/api/odoo/query-no-cache',
  '/api/route-resolver',
  '/api/sitemap/urls/categories',
  '/api/sitemap/urls/products',
  '/web/health',
  '/__nuxt_error',
  // ... system routes
]
```

**Routes That Bypass Cache:**
- `/cart` - Shopping cart (always fresh)
- `/my-account/*` - User account pages (personal data)

#### Configuration

```typescript
// nuxt.config.ts
nitro: {
  storage: {
    cache: {
      driver: process.env.NUXT_STORAGE_DRIVER, // 'redis'
      url: process.env.NUXT_STORAGE_URL,       // 'redis://localhost:6379'
      retry: {
        retries: 3,
        delay: 1000,
      },
      connectTimeout: 10000,
      lazyConnect: true,
    },
  },
}
```

#### Environment Variables

```bash
# .env
NUXT_STORAGE_DRIVER=redis
NUXT_STORAGE_URL=redis://localhost:6379
NUXT_SWR_CACHE_TIME=3600  # Cache duration in seconds
```

#### Benefits

- ✅ **Automatic caching** of all page responses
- ✅ **Device-specific cache** for optimal mobile/desktop experience
- ✅ **SWR (Stale-While-Revalidate)** for better UX
- ✅ **Intelligent bypass** for dynamic content
- ✅ **Redis clustering** support for scalability

#### Cache Invalidation

The cache automatically invalidates based on:
- **TTL (Time To Live)** - Set by `NUXT_SWR_CACHE_TIME`
- **Manual bypass** - For user-specific routes
- **Route exclusion** - For API endpoints and system routes

This ensures that static content like product pages are served lightning-fast from cache, while dynamic content remains fresh and personalized.


## 🛒 Cart Cache System

The cart cache system uses Redis to store shopping cart data for optimal performance and real-time synchronization with ODOO.

#### Configuration

The cart cache is configured in `nuxt.config.ts` with dedicated Redis storage:

```typescript
// nuxt.config.ts
nitro: {
  storage: {
    cart: {
      driver: process.env.NUXT_STORAGE_DRIVER,     // 'redis'
      url: process.env.NUXT_STORAGE_URL,           // Redis connection URL
      ttl: process.env?.NUXT_SWR_CACHE_TIME || 0,  // No TTL for cart (persistent)
      retry: {
        retries: 3,
        delay: 1000,
      },
      connectTimeout: 10000,
      lazyConnect: true,
    },
    stock: {
      driver: process.env.NUXT_STORAGE_DRIVER,
      url: process.env.NUXT_STORAGE_URL,
      ttl: process.env?.NUXT_SWR_CACHE_TIME || 3600, // 1 hour TTL for stock
      retry: {
        retries: 3,
        delay: 1000,
      },
      connectTimeout: 10000,
      lazyConnect: true,
    },
  },
}
```

#### How It Works

The cart cache operates through three main components:

1. **Cart Load API** - Retrieves cart data from Redis
2. **Cart Management Plugin** - Automatically updates Redis when cart changes
3. **Cart Composable** - Frontend interface for cart operations

#### Cart Load API

```typescript
// server/api/odoo/cart-load.get.ts
export default defineEventHandler(async (event: any) => {
  const websiteId = 1
  const session = await useSession(event, {
    password: 'b013b03ac2231e0b448e9a22ba488dcf',
  })
  const keyName = `cache:cart:${session?.id}`
  
  // Load cart from Redis using 'cart' storage
  const data = await useStorage('cart').getItem(keyName)

  // Enhance cart items with real-time stock data from 'stock' storage
  for (const orderLine of data?.cart?.order?.websiteOrderLine || []) {
    const stock = await useStorage('stock').getItem<string>(
      `stock:product-${orderLine?.product?.id}`,
    )
    
    try {
      (orderLine.product as CustomProductWithStockFromRedis).stock = 0
      if (stock) {
        (orderLine.product as CustomProductWithStockFromRedis).stock = stock?.[websiteId] || 0
      }
    }
    catch (e) {
      console.log(e)
    }
  }

  return data || {}
})
```

#### Cart Management Plugin

The plugin automatically updates Redis cache whenever cart-related operations occur:

```typescript
// server/plugins/manage-cart.ts
export default defineNitroPlugin((nitro) => {
  nitro.hooks.hook('beforeResponse', async (event, { body }) => {
    if (event.method == 'POST') {
      await cartAddItem(event, body)
      await cartRemoveItem(event, body)
      await cartUpdateItem(event, body)
      await updateAddress(event, body)
      await addAddress(event, body)
      await applyCoupon(event, body)
      await applyGiftCard(event, body)
      await clearCartAfterPaymentConfirmation(event, body)
    }
  })
})

// Add item to cart and update Redis
async function cartAddItem(event: any, body: any) {
  const requestBody = await readBody(event)
  
  if (requestBody[0]?.mutationName === MutationName.CartAddItem) {
    updateCart(event, body.cartAddMultipleItems)
  }
}

// Update address in cart cache
async function addAddress(event: any, body: any) {
  const requestBody = await readBody(event)
  if (requestBody[0]?.mutationName === MutationName.AddAddress) {
    const session = await useSession(event, {
      password: 'b013b03ac2231e0b448e9a22ba488dcf',
    })

    const keyName = `cache:cart:${session?.id}`
    const currentCart = (await useStorage('cart').getItem<{ cart: Cart }>(keyName)) || ({} as any)
    
    if (requestBody[1].type === 'Shipping') {
      currentCart.cart.order.partnerShipping = body.addAddress
    }
    else {
      currentCart.cart.order.partnerInvoice = body.addAddress
    }

    const reducedCart = reduceCart(currentCart as Cart)
    await useStorage('cart').setItem(keyName, reducedCart)
  }
}

// Clear cart after successful payment
async function clearCartAfterCreditCardPaymentConfirmation(event: any, body: any) {
  const requestBody = await readBody(event)
  
  const paymentSuccess = body?.paymentConfirmation?.order?.lastTransaction?.state === 'Authorized'
    || body.paymentConfirmation?.order?.lastTransaction?.state === 'Confirmed'

  if (requestBody[0]?.queryName === QueryName.GetPaymentConfirmation) {
    const session = await useSession(event, {
      password: 'b013b03ac2231e0b448e9a22ba488dcf',
    })
    
    const keyName = `cache:cart:${session?.id}`
    if (paymentSuccess) {
      await useStorage('cart').removeItem(keyName)
    }
  }
}
```

#### Frontend Cart Composable

```typescript
// composables/useCart.ts
export const useCart = () => {
  const { $sdk } = useNuxtApp()
  const cart = useState<Cart>('cart', () => ({}) as Cart)
  
  // Load cart from Redis cache
  const loadCart = async () => {
    try {
      loading.value = true
      const { data } = await useFetch<{ cart: Cart }>(`/api/odoo/cart-load`)

      if (!data.value?.cart) return

      cart.value = data.value.cart
      cartCounter.value = Number(data.value.cart?.order?.websiteOrderLine?.length)
      frequentlyTogetherProducts.value = (data.value.cart.frequentlyBoughtTogether || [])
    }
    catch (error: any) {
      return toast.error(error.data.message)
    }
    finally {
      loading.value = false
    }
  }

  // Add item to cart (automatically updates Redis via plugin)
  const cartAdd = async (id: number, quantity: number) => {
    const params: MutationCartAddMultipleItemsArgs = {
      products: [{ id, quantity }],
    }

    try {
      loading.value = true
      
      const data = await $sdk().odoo.mutation<MutationCartAddMultipleItemsArgs, CartAddItemResponse>(
        { mutationName: MutationName.CartAddItem }, params,
      )

      // Cart is automatically updated in Redis via manage-cart plugin
      cart.value = data.cartAddMultipleItems
      cartCounter.value = Number(cart.value?.order?.websiteOrderLine?.length)
      toast.success('Product has been added to cart')
    }
    catch (error: any) {
      return toast.error(error.data.message)
    }
    finally {
      loading.value = false
    }
  }
}
```

## 📦 Stock Cache System

The stock cache system uses Redis to store real-time inventory data, ensuring users can only add available products to their cart.

#### Configuration

Stock data is stored in a dedicated Redis storage with TTL for freshness:

```typescript
// nuxt.config.ts
nitro: {
  storage: {
    stock: {
      driver: process.env.NUXT_STORAGE_DRIVER,
      url: process.env.NUXT_STORAGE_URL,
      ttl: process.env?.NUXT_SWR_CACHE_TIME || 3600, // 1 hour TTL
      retry: {
        retries: 3,
        delay: 1000,
      },
      connectTimeout: 10000,
      lazyConnect: true,
    },
  },
}
```

#### How It Works

The stock system operates through three main components:

1. **Stock Enhancement Plugins** - Automatically append stock data to product responses
2. **Cart Integration** - Prevents adding out-of-stock items to cart
3. **Frontend Validation** - Disables "Add to Cart" when stock is zero

#### Stock Enhancement Plugins

**For Product Lists:**
```typescript
// server/plugins/manage-product-list.ts
export default defineNitroPlugin((nitro) => {
  nitro.hooks.hook('beforeResponse', async (event, { body }) => {
    const websiteId = 1
    const requestBody = await readBody(event)

    if (event.method == 'POST' && requestBody[0]?.queryName === QueryName.GetProductTemplateListQuery) {
      for (const product of (body as any).products.products) {
        const stock = await useStorage('stock').getItem<string>(
          `stock:product-${product.firstVariant.id}`,
        )

        try {
          product.stock = 0
          if (stock) {
            product.firstVariant.stock = stock?.[websiteId] || 0
          }
        }
        catch (e) {
          console.log(e)
        }
      }
    }
  })
})
```

**For Individual Products:**
```typescript
// server/plugins/manage-product.ts
export default defineNitroPlugin((nitro) => {
  nitro.hooks.hook('beforeResponse', async (event, { body }) => {
    const websiteId = 1

      const id = (body as any).productVariant?.product?.id

      const stock = await useStorage('stock').getItem(`stock:product-${id}`)

      (body as any).productVariant.product.stock = stock?.[websiteId] || 0
    }
  })
})
```

#### Frontend Stock Validation

The product page automatically disables the "Add to Cart" button when stock is zero:
